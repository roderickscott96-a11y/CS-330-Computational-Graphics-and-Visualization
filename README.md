# CS-330 Computational Graphics and Visualization

This repository contains work completed for CS 330: Computational Graphics and Visualization.

Throughout this course, I developed a 3D scene using C++, OpenGL, textures, lighting, camera navigation, and reusable rendering functions.

The final project demonstrates my ability to:
- Construct 3D objects using multiple primitive shapes
- Apply textures and materials to objects
- Implement ambient, diffuse, and specular lighting
- Create multiple light sources
- Implement camera movement and perspective/orthographic views
- Organize rendering code using reusable functions
