# CS 330: Computational Graphics and Visualization

This repository contains my final project for CS 330: Computational Graphics and Visualization. The project demonstrates the development of a fully realized 3D scene using C++, OpenGL, textures, lighting, camera navigation, and reusable rendering functions.

My final scene recreates a computer desk environment containing a monitor, coffee mug, books, pencil holder, pencils, and a textured desktop. The project was developed throughout multiple milestones, with each milestone introducing additional graphics techniques such as object construction, camera movement, texturing, lighting, and scene organization.

## How Do I Approach Designing Software?

Working on this project helped me improve my ability to break a larger visual idea into smaller components that could be developed individually. Instead of attempting to create the entire scene at once, I identified the primitive shapes needed for each object and combined them to create more complex models.

My design process involved starting with the basic structure of the scene, testing object placement, and then gradually adding additional features. I added camera navigation, textures, materials, lighting, and additional objects as the project progressed. I also used feedback and visual testing to make adjustments. For example, I revised the monitor stand and base so that the monitor appeared connected and properly positioned on the desktop instead of floating.

This type of incremental design process can be applied to future projects by dividing complicated problems into smaller pieces, developing each component separately, and continuously testing how those components work together.

## How Do I Approach Developing Programs?

One development strategy I used throughout this project was modularization. I created reusable functions for rendering individual objects instead of placing all of the scene code inside one large function. This made the program easier to understand and made it simpler to adjust individual objects without affecting the rest of the scene.

Iteration played a major role in completing the project. I frequently compiled and ran the program to check object positions, textures, lighting, camera controls, and overall appearance. When something did not look correct, I adjusted the values and tested the scene again. This process was especially important when positioning objects and correcting issues such as the monitor stand and base.

My development approach evolved throughout the milestones. At the beginning of the course, I focused mainly on getting basic shapes to render correctly. By the end of the project, I was thinking more about code organization, reusable functions, materials, textures, lighting, user interaction, and how all of those systems worked together.

## How Can Computer Science Help Me Reach My Goals?

Computational graphics and visualization gave me experience with several concepts that can support my future education in computer science. I gained additional practice with C++, debugging, mathematics, object transformations, libraries, user input, and organizing larger programs. I also gained a better understanding of how graphics applications transform code and mathematical values into interactive visual environments.

Professionally, these skills can be useful in software development, game development, simulations, visualization tools, and other interactive applications. Even if I do not work directly in computer graphics, the problem-solving, debugging, modular programming, and iterative development skills I practiced throughout this course can be applied to many areas of software development.
